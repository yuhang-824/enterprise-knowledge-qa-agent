# 难点、学习结论与下一步

## 最难的问题

检索到一份支持答案的资料，不等于已经排除冲突。实现因此区分“发现摘要”“读取原文”“证据核验”，并检查所有相关启用来源的覆盖，避免只读取D01就忽略D02。

另一个问题是引用存在不等于引用支持主张。模型不能任意生成答案再贴一个文档ID；回答工具必须使用已读且支持所问事实的source_id，由核验值生成有限模板。这样能验证本题的明确事实，但不能把它宣传为通用语义问答能力。

对话历史既有用也有风险：它能让“那需要哪些材料”承接报销领域，却不能使上一轮助手说过的数字成为制度证据。制度适用权也必须来自用户明确输入，而不是模型或资料里的指令。

## 实现中可以核对的结论

- 没读到冲突文档与确实无冲突是两种状态。
- 版本日期不能替代明确的制度适用关系。
- 资料更新时要同步答案、原文引用和内容指纹。
- 拒绝无依据回答、保留缺口，是可靠问答的一部分。
- 规则核验和真实模型决策效果要分别验证，不能用离线通过率代替真实效果。

这些是本轮工程实现的总结，不代替候选人的个人学习经历。
